# 🎸 Nirvana Vault

Nirvana Vault es un proyecto web dedicado a Nirvana, desarrollado como parte de un proyecto educativo de Desarrollo Web.

El sitio funciona como un archivo digital donde se puede conocer la historia de la banda, sus integrantes, álbumes y canciones.

## 🌐 Sitio web

https://nirvana-vault.vercel.app/

## 📌 Funciones

- 🏠 Página de inicio.
- 📖 Historia de Nirvana.
- 👥 Información sobre los integrantes de la banda.
- 🎵 CRUD de canciones.
- 🔎 Buscador de canciones.
- 💾 Almacenamiento de canciones mediante LocalStorage.
- ✏️ Registro, edición y eliminación de canciones.
- ✅ Validación de datos al registrar y editar.
- 📚 Enciclopedia de álbumes.
- 💿 Información sobre los principales álbumes de Nirvana.

## 💿 Álbumes incluidos

- Bleach
- Nevermind
- Incesticide
- In Utero
- MTV Unplugged in New York
- Live at Reading

## 🚧 Desarrollo

Nirvana Vault continúa en desarrollo.

Entre las funciones planeadas se encuentra una vista individual para cada álbum, donde se podrá consultar su lista de canciones, información, contexto e interpretación.
