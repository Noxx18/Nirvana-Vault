
# 🎸 Nirvana Vault

Nirvana Vault es un proyecto personal de desarrollo web dedicado a preservar, explorar y divulgar la historia y el legado musical de Nirvana.

Desarrollado con React y Vite, combina una enciclopedia musical interactiva con un sistema de gestión de canciones, ofreciendo información sobre la banda, sus integrantes, su discografía y las interpretaciones de sus composiciones.

El proyecto se encuentra en constante evolución, incorporando nuevas funcionalidades, contenido y mejoras visuales.

## 🌐 Sitio web

### 💿 Enciclopedia musical

Exploración interactiva de los siguientes álbumes:

| Álbum | Año | Tipo |
|---|---|---|
| Bleach | 1989 | Estudio |
| Nevermind | 1991 | Estudio |
| Incesticide | 1992 | Recopilatorio |
| In Utero | 1993 | Estudio |
| MTV Unplugged in New York | 1994 | En vivo |
| Live at Reading | 2009 | En vivo |

Cada álbum incluye:

- Portada original.
- Año de lanzamiento.
- Información general.
- Canciones destacadas.
- Lista de canciones interactiva.
- Descripción de cada canción.
- Contexto histórico.
- Significado e interpretación.
- Enlaces a Spotify y YouTube.

## 🚀 Instalación local

Clonar el repositorio:

```bash
git clone https://github.com/Noxx18/Nirvana-Vault.git
```

Ingresar a la carpeta del proyecto:

```bash
cd Nirvana-Vault
```

Instalar las dependencias:

```bash
npm install
```

Ejecutar el servidor de desarrollo:

```bash
npm run dev
```
